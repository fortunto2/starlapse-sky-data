# Starlapse sky dataset

Sky brightness and meteor observations measured by [Starlapse](https://starlapse.app), an
iPhone long-exposure camera, from the photos of people who chose to contribute them.
CC BY 4.0. Every release here is archived on Zenodo with a DOI; the photos are published with
the same tables on Hugging Face (`superduperai/starlapse-sky`).

No release yet: the first comes once Starlapse 1.1 is live and the first readings arrive.
Method, file layout and caveats are in each release's `README.md`; the code that measures
and exports is in [fortunto2/starlapse](https://github.com/fortunto2/starlapse)
(`Sources/SkyMeter`, `server/dataset/export.py`).
